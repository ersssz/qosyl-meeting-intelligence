# ONE-PAGER — Qosyl Meeting Intelligence

> Одна страница. Один экран. Одна понятная идея на блок.

## Проблема

После встречи решения и поручения остаются в записи или переписке. Руководитель тратит
время на ручной протокол, а владельцы, сроки и нерешённые вопросы теряются.

## Решение

Qosyl принимает MP3/WAV/M4A или готовый транскрипт и формирует executive summary,
темы, решения, открытые вопросы, Action Items и риски с проверяемыми цитатами.

## Live Demo

`Аудио → Transcript + timestamps → AI-протокол → Grounding → CSV/JSON/Markdown`

**Замер на тестовом 2-минутном аудио:** [время обработки] · [доля верных поручений]

## Почему можно доверять

- Решения, поручения, вопросы и риски содержат дословную цитату из транскрипта.
- Неподтверждённый вывод не исчезает: он получает `NEEDS HUMAN REVIEW` и низкий confidence.
- ИИН, телефоны, карты и IBAN маскируются до аналитической модели.
- Аудио и полный транскрипт не сохраняются в audit DB; каждый запуск имеет `trace_id`.

## Deploy anywhere

Одинаковые контракты провайдеров позволяют переключить Gemini API на локальные
`faster-whisper + Ollama/Qwen` только через окружение. Это даёт быстрый пилот сегодня и
полностью self-hosted развёртывание для конфиденциальных встреч завтра.
